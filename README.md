**你的桌面级“即时传译员”—— 专为高频中英切换场景打造的免安装输入外挂。**
当你正在使用某些重型软件（海外游戏、无中文环境的专业工具）时，是否厌倦了“切出软件 -> 打开网页翻译 -> 复制英文 -> 切回软件 -> 粘贴”的繁琐流程？
**“中英输入助手”** 
完美解决了这个痛点。只需按下快捷键，原地呼出极简翻译窗，输入中文即可瞬间转为地道英文并**自动注入**到原软件的输入框中，让你的创作思绪永不被打断。
---
### ✨ 核心亮点 (Features)

* 🎯 **“物理级”焦点接管（黑科技）**
    针对部分响应迟钝或拦截系统粘贴指令的“顽固软件”，独创“物理外挂级”焦点恢复机制。自动记录呼出位置，输出前模拟真实的鼠标左键点击，**100% 强制拿回输入焦点**。
* ⚡ **原生级按键注入 & 真人打字模拟**
    摒弃传统的“污染剪贴板 + 模拟 Ctrl&V”方案，采用底层 Windows `SendInput` API 直接注入 Unicode 字符。内置 `15ms` 真人打字频率模拟，既快又稳，彻底告别字符丢失或顺序错乱。
* 🧠 **谷歌标准翻译 + 高频本地词典**
    接入 Google Translate 官方标准接口，确保翻译结果（如专有名词、日常短语）正规、准确、符合母语直觉。内置高频词汇本地缓存，常用词条“零延迟”瞬间上屏。
* 🕹️ **智能跟随与悬浮 UI**
    提供“记忆上次位置”与“光标上方自动跟随”两种定位模式。UI 采用现代化圆角胶囊设计，不遮挡视线，支持鼠标随意拖拽。
* 📦 **极致轻量，即插即用**
    纯绿色单文件 `.exe`，无需安装环境，不依赖管理员权限。提供右下角系统托盘菜单，支持一键设置**开机自启**与沉浸式的“呼吸灯”状态提醒。

---

### ⌨️ 如何使用 (How to Use)
1.  **运行程序**：双击打开 `ChineseInputHelper.exe`，右下角系统托盘会出现一个蓝色的“E”字呼吸灯图标。
2.  **定位输入**：在任何你需要输入英文的软件（如视频剪辑软件、浏览器、文档）中，将鼠标光标点在输入框内。
3.  **一键呼出**：按下全局快捷键 **`Ctrl + Shift + Z`**，悬浮翻译窗会立即弹到你的光标上方。
4.  **输入与上屏**：
    * 直接输入中文（如“石头人”），界面会自动展示翻译结果（如“Stone man”）。
    * 使用键盘 **`↑` `↓` `←` `→`** 或 **数字键 `1-8`** 选择候选词。
    * 按下 **`Enter` (回车)** 或 **`Space` (空格)**，英文单词将瞬间自动打在原输入框中！
---

### 🛠️ 托盘快捷菜单 (Tray Menu)
右键点击系统托盘的蓝色“E”图标，你可以：
* **启用/停用**：暂时关闭快捷键监听。
* **💻 开机自启**：一键写入/移除系统注册表，实现开机自动后台静默运行。
* **📍 定位方式**：切换悬浮窗是“出现在光标上方”还是“记忆你上次拖拽的位置”。
* **退出**：安全退出程序。
